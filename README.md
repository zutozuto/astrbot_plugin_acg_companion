# ACG 群友

让 AstrBot 偶尔主动接话：分享 ACG 音乐和视频、开轻松玩笑、跟进聊过的话题，也可以分享远程生成的图片。独立运行，可与现有主动聊天插件共存，语气参考当前群的人格。

## 功能

| 功能 | 行为 |
| --- | --- |
| 主动分享 | 从网易云 ACG 榜、QQ 音乐动漫/游戏榜、B 站 ACG 热门选择内容，附封面、标题、作者、短评和原站链接 |
| 轻松讨要 | 晒新购物后偶尔接一句“也给我整一份”；星期四随机发玩梗文案 |
| 主动提问 | 联机、约饭、出游话题过一阵后再接话；有人求助而讨论无果时，稍后问是否解决 |
| 图片分享 | 支持魔搭、OpenAI 兼容生图、Seedream 和图片直链；模型自行选择吃喝、见闻、创作等配文口吻 |
| 网页控制台 | 查看状态、调整配置、预览语气、生图测试、单独重写配文，确认后手动试发 |
| 可选歌曲 | 实验性的 MiniMax music_generation 协议适配；需要自行准备有效服务，默认关闭 |

识别到话题不代表一定发送。模型会结合后续聊天决定是否适合接话；已解决、拒绝、取消和过期话题会跳过，同一话题或作品不重复发送。

## 安装与开始使用

需要 AstrBot **4.29.1 或更新版本**、QQ 的 OneBot v11（aiocqhttp）适配器，以及一个 OpenAI 兼容文本模型提供商。控制台依赖该版本的插件 Web API 与 Views。

1. AstrBot **插件管理 → 从链接安装**，填写 `https://github.com/zutozuto/astrbot_plugin_acg_companion`。
2. 在插件配置中填写目标群 UMO，例如 `aiocqhttp:GroupMessage:123456789`。前缀使用自己的平台实例 ID。
3. 选择自己的**文本模型提供商 ID**，只使用该提供商，不自动切换其他模型。
4. 打开 **插件管理 → ACG 群友 → 详情 → Views → 控制台**，先测试语气。

首次加载后需观察到目标群的新真人消息才开始自动发言，不读取安装前的群历史来生成追问。更新后重载插件，并关闭旧控制台再打开。

## 配置

常用设置直接显示，高级频率、额度和歌曲实验配置默认折叠。大多数情况下只需填写群和模型，其余保留默认。

| 常用项 | 默认及说明 |
| --- | --- |
| 每天自动发言上限 | `2-5`：每天随机取 2 至 5 条作为上限；`3` 为固定上限，`0` 暂停自动发言，不强行凑数 |
| 安静时段 | `02:00-08:00`，北京时间，支持跨午夜；起止相同表示全天允许 |
| 功能开关 | 分享、话题跟进和玩笑默认开启；自动生图和歌曲默认关闭 |
| 生图接口 | 魔搭地址可留空，填写自己的 Token；默认模型 `Tongyi-MAI/Z-Image-Turbo` |

高级设置保留了必要的费用与频率限制：真人停聊至少 5 分钟、本插件间隔 90 分钟、避让机器人最近发言 10 分钟；每群每天最多 8 次文本请求，所有群共用 16 次。其他机器人 QQ 号可加入忽略列表。

每群每天默认可手动试发 10 次，与自动发言额度分开。手动提交新图默认每天 2 次、至少间隔 60 秒，可在高级设置调整；复用缓存图片不占新图次数。失败和结果不确定的请求也计入相应额度，不自动重试。

## 网页测试与命令

- **测试与状态**：选择群、类型和来源生成预览。榜单及真实待跟进话题可以手动试发；模拟场景只供查看语气。
- **生图测试**：不必开启自动生图。填写主题，配文留空由模型写；手填配文优先。默认复用缓存，确需新图时勾选“重新请求接口生成新图”。
- **模型重写配文**：只改当前图片的配文，不重新生图。旧图片没有保存主题时，先填写图中内容；失败保留图片和原配文。
- **插件设置**：保存后立即生效。密钥留空保留原值，勾选清除才删除，页面不读回完整密钥。

所有预览均不自动发到群里。点击发送后使用预览中的图片与配文，不再调用模型；预览十分钟有效。同一预览最多发送一次，超时或结果不确定时不会重发。手动试发跳过自动冷却和安静时段，仍检查插件开关、群暂停、内容去重和独立试发额度。

管理员群命令：`/群友状态`、`/群友预览`、`/群友暂停`、`/群友恢复`。命令预览只查看计划，不调用模型；暂停和恢复只作用于当前目标群。

## 图片接口

| 类型 | 配置方式 |
| --- | --- |
| 魔搭 | API 地址留空或填 `https://api-inference.modelscope.cn/v1/images/generations`，使用自己的 ModelScope Token 和有 API-Inference 权限的文生图模型 |
| OpenAI 兼容 | 填完整 `/images/generations` 地址或 `/v1` 基地址、该服务的密钥及模型；支持 `data[0].url` / `data[0].b64_json` |
| Seedream | 火山方舟 `/api/v3` 基地址或完整生图地址；官方地址自动识别，转发站在高级设置将接口类型选为 `seedream` |
| 图片直链 | HTTPS 地址中包含 `{prompt}`，替换主题后 GET 返回图片或支持的 JSON；免鉴权服务可不填密钥 |

接口类型默认 `auto`。服务有私有字段、不同异步协议、NovelAI ZIP 协议时，需要另做适配，不能仅靠 URL 通用接入。Kimi 聊天密钥不能用于魔搭或其他生图服务。

免费额度、模型可用性和价格由服务方决定；魔搭的调用可能消耗魔粒，不承诺长期无限免费。插件不自动购买额度。图片和歌曲默认全局至少隔三天尝试一次生成，失败也占间隔；两个群可复用同一份作品，各群只分享一次。

歌曲接口需自行填写仍有效的 HTTPS 地址、密钥和模型，按 MiniMax `music_generation` 风格提交原创歌词并读取 `data.audio` 的音频 URL。尚无已验证的长期免费服务，不预填付费服务或型号。

参考：[魔搭 API-Inference](https://modelscope.cn/docs/model-service/API-Inference/intro)、[魔搭额度](https://modelscope.cn/docs/model-service/API-Inference/limits)、[火山方舟图片 API](https://www.volcengine.com/docs/82379/1541523)。

## 成本、数据和限制

观察消息、关键词筛选、调度、去重和榜单获取不调用 LLM。动作满足本地条件后，单次文本请求同时判断是否发言并生成短句，输出最多 320 tokens；不上传音视频供模型分析。人格只取开头最多 2200 字符，缓存十分钟。

独立图片配文只使用主题和最多 600 字符的人格，输出最多 128 tokens，不携带整段群聊、不额外识图。自动图片分享复用原有决策请求。配文依据生图提示词，实际图片偏离主题时可能有描述偏差；配文缓存后不自动重复请求。

只观察文字，纯图片晒物、没有关键词的求助可能漏掉。追问、自动生成和分享均不保证按点发生：活跃聊天、冷却、额度或无人回应会使任务延后或取消。两个主动插件没有共享发送锁，只能尽力避让。

运行数据位于 AstrBot 的 `data/plugin_data/astrbot_plugin_acg_companion/`：每群最近最多 120 条文字记录、每条最多 500 字符，超过两天清理；动作与去重记录约保留 32 天。密钥留在本机插件配置，仓库不包含运行配置、群聊、媒体缓存或数据库。

## 开发验证

在可导入 AstrBot 的 Python 环境中运行；使用源码安装时可设置 `ASTRBOT_APP` 指向 AstrBot 项目根目录。

```sh
python -B -m unittest discover -s tests -q
node --test tests/test_webui.cjs
```

测试使用临时数据库和模拟接口，不向 QQ 群发送消息，也不请求真实文本、生图或歌曲服务。
